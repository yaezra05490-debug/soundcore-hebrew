# אוזניות Soundcore בעברית

תוכנה חינמית למחשב (Windows 10/11) לשליטה באוזניות Soundcore: מצבי סינון רעשים, אקולייזר, הגדרת הנגיעות, סוללה ועוד, עם ממשק מלא בעברית.

התוכנה מבוססת על [OpenSCQ30](https://github.com/Oppzippy/OpenSCQ30), תוכנה חופשית בקוד פתוח, ונוספו לה:

- **תמיכה ב-Soundcore Liberty 5 Pro.** התמיכה הבסיסית מבוססת על [PR #414](https://github.com/Oppzippy/OpenSCQ30/pull/414) של Igor Quirino, שעוד לא נכלל בגרסה הרשמית. נוספה לה קריאה של ההגדרות האמיתיות מהאוזניות ושל סוללת הקופסה.
- **תרגום מלא לעברית.** התרגום שהיה בפרויקט היה חלקי, והושלם ותוקן.
- **קיצורי מקלדת** להחלפת מצב השמע ולהצגת הסוללה.

## ⬇️ הורדה

### [להורדת התוכנה (קובץ ZIP)](https://github.com/yaezra05490-debug/soundcore-hebrew/releases/latest/download/Soundcore-Hebrew.zip)

הקישור מוביל תמיד לגרסה האחרונה. כל הגרסאות נמצאות [בדף הגרסאות](https://github.com/yaezra05490-debug/soundcore-hebrew/releases).

## התקנה

1. מורידים את קובץ ה-ZIP, לוחצים עליו בכפתור ימני ובוחרים **"חלץ הכל"**. אפשר לחלץ לכל תיקייה.
2. מצמידים את האוזניות למחשב בהגדרות הבלוטות' של Windows, אם עוד לא הוצמדו.
3. מפעילים את **`openscq30-gui.exe`** מהתיקייה שחולצה.
   - התוכנה לא חתומה דיגיטלית, ולכן ייתכן ש-Windows יציג חלון כחול של הגנה. כדי להמשיך לוחצים **"מידע נוסף"** (More info) ואז **"הפעל בכל זאת"** (Run anyway).
4. בתוכנה לוחצים **"הוסף מכשיר"**, בוחרים את דגם האוזניות ואז את האוזניות עצמן מהרשימה.

**אם התוכנה נפתחת באנגלית:** נכנסים ל-**Settings**, בוחרים ב-**Preferred Language** את **עברית** ופותחים את התוכנה מחדש. כשהשפה של Windows היא עברית, התוכנה נפתחת בעברית מעצמה.

כל שינוי בתוכנה נשלח לאוזניות מיד ונשמר בהן. ההגדרות נשארות גם כשמחברים את האוזניות לטלפון.

## קיצורי מקלדת (Liberty 5 Pro בלבד)

מפעילים את **`SoundcoreHotkeys.exe`** מאותה תיקייה. זו תוכנת רקע קטנה בלי חלון, והקיצורים עובדים מכל חלון:

| קיצור | פעולה |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | סינון רעשים |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> | מצב שקוף |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> | מצב רגיל |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>A</kbd> | אדפטיבי |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | חלון סוללה (שמאל / ימין / קופסה) |

- הקיצורים עובדים רק אחרי שהאוזניות נוספו פעם אחת בתוכנה הראשית.
- כשהתוכנה הראשית פתוחה ומחוברת לאוזניות, ייתכן שהקיצור לא יצליח להתחבר. במקרה כזה תופיע הודעה.
- **כדי שהקיצורים יעלו עם Windows:** לוחצים <kbd>Win</kbd>+<kbd>R</kbd>, כותבים `shell:startup` ולוחצים Enter. בתיקייה שנפתחת יוצרים קיצור דרך ל-`SoundcoreHotkeys.exe`: גוררים את הקובץ לתיקייה תוך כדי לחיצה על <kbd>Alt</kbd>.
- **כדי לכבות את הקיצורים:** מוחקים את קיצור הדרך מאותה תיקייה וסוגרים את SoundcoreHotkeys במנהל המשימות.

## מה עובד ב-Liberty 5 Pro (נבדק על קושחה 05.33)

**עובד, והתוכנה מציגה את הערכים האמיתיים מהאוזניות:**
- מצבי שמע (סינון רעשים, שקוף, רגיל, אדפטיבי)
- רמת סינון 1–5 ומצב תחבורה (מטוס / רכב)
- הפחתת רעשי רוח
- אקולייזר אישי
- הגדרת הנגיעות בכל אוזנייה
- LDAC, ‏Easy Chat, צלילי מערכת וכיבוי אוטומטי
- סוללה לכל אוזנייה ולקופסה. הסוללה של הקופסה מתעדכנת רק אחרי שהאוזניות היו בתוכה.

**עוד לא נתמך, ואפשר לשנות רק באפליקציה הרשמית:** חיבור לשני מכשירים, פרופילי אקולייזר מוכנים, פקודות קוליות והנחיות קוליות, בדיקת התאמה (Fit Test), ‏HearID ועדכון קושחה.

בדגמי Soundcore אחרים התוכנה עובדת כמו OpenSCQ30 הרגילה, אבל בעברית. רשימת הדגמים הנתמכים נמצאת [בדף הפרויקט המקורי](https://github.com/Oppzippy/OpenSCQ30#supported-devices).

## שאלות

- **האם זה רשמי?** לא. זו תוכנה חופשית שאינה קשורה ל-Anker או ל-Soundcore.
- **האם צריך חשבון או אינטרנט?** לא. התוכנה מדברת עם האוזניות ישירות דרך הבלוטות'.
- **איפה התוכנה שומרת את ההגדרות שלה?** בתיקייה `%APPDATA%\openscq30`.
